# One pnpm + Turborepo monorepo; packages only point down

Razzlr is one monorepo: four TypeScript apps (web, api, sync, worker), shared packages, and one uv workspace for Python that must sit next to the models. Packages never depend on apps, and the core chain is schema → doc → renderer → editor, so a change can't leak sideways. `pnpm lint` enforces it: a check over every workspace's declared dependencies (packages never depend on apps or test suites), plus an ESLint rule that forbids reaching another workspace by relative path. The editor is a package, not a folder in the web app, so it stays client-only and testable on its own.
